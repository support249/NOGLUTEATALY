# NOGLUTEATALY

Rebuild a gluten-free food-tour website for Rome as a Next.js + React app.

The original WordPress/Elementor site is archived in `nogluteataly.com/` and used as a content source. The UI will be redesigned later; this phase is structure and content, not visual fidelity.

## Core goals

- Recreate the existing site information architecture in Next.js
- Keep copy, tours, FAQ, contact details, and blog posts available
- Leave styling simple so a later redesign can replace it without redoing content
